# C Assignment Solutions

A collection of standalone C programs solving ten introductory programming assignments. Each question is provided as its own source file in `c_assignment/`.

## Programs

- `q01_cab_fare.c` — Cab fare calculation
- `q02_exam_submission.c` — Exam submission eligibility
- `q03_treasure_hunt.c` — Treasure hunt logic
- `q04_dollars_cents.c` — Dollars and cents conversion
- `q05_car_mileage.c` — Car mileage calculation
- `q06_integer_to_binary.c` — Integer-to-binary conversion
- `q07_debt_repay.c` — Debt repayment calculation
- `q08_employee_level.c` — Employee level determination
- `q09_number_of_days.c` — Number of days calculation
- `q10_electricity_bill.c` — Electricity bill calculation

Compile an individual program with a C compiler, for example: `gcc c_assignment/q01_cab_fare.c -o cab_fare`.
